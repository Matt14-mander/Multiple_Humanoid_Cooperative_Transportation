# Multiple_Humanoid_Cooperative_Transportation

## MuJoCo projects

- `single-tron2-chip`: single WFYG_TRON2A policy/deployment scaffold and the
  checked 6D external-wrench GRU/ONNX bundle used for first-stage sim2sim.
- `dual-tron1-mujoco`: dual WF_TRON1A + AIRBOT cooperative-carry project.
- `dual-tron2-mujoco`: dual official WFYG_TRON2A (wheel-leg + 6-DoF arm +
  gripper) fixed-base cooperative-carry baseline.
